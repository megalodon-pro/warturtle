# My project

> А military‑themed game called War Turtle.

---

## Install

The installation is completed in 3 steps.

### Step 1: Download
On the repository page, click the green **Code** button and select **Download ZIP**.

### Step 2: Unpack
Extract the downloaded ZIP file to any folder on your computer.

### Step 3: Build
Run `builder.bat` (double‑click it). This will download all required files automatically.  
Wait until you see the message **"Build complete!"** (about 1‑2 minutes).

---

#### Using
After the build is complete:

- **Option A:** Double‑click the shortcut `War Turtle` on your desktop.
- **Option B:** Open the `dist` folder and run `WarTurtle.exe` directly.

> ⚠️ **Note:** The `dist` folder appears only after you complete Step 3.

---

##### Requirements

Windows 7 or newer
